## Evidence-backed summary

- However, in high-frequency and large-scale transaction scenarios, blockchain performance faces serious challenges, limiting its further application. ([[.raw/papers/bpo-cbs-a-data-driven-blockchain-performance-optimization-framework-for-cloud-blockchain-services#Page 1|PDF p. 1]]).
- Therefore, blockchain performance optimization (BPO) has become a key field. ([[.raw/papers/bpo-cbs-a-data-driven-blockchain-performance-optimization-framework-for-cloud-blockchain-services#Page 1|PDF p. 1]]).
- Recent BPO methods that adjust blockchain configuration parameters like block size, offer benefits such as low cost and easy deployment. ([[.raw/papers/bpo-cbs-a-data-driven-blockchain-performance-optimization-framework-for-cloud-blockchain-services#Page 1|PDF p. 1]]).
- This paper proposes a data-driven BPO framework (BPO-CBS) for CBS. ([[.raw/papers/bpo-cbs-a-data-driven-blockchain-performance-optimization-framework-for-cloud-blockchain-services#Page 1|PDF p. 1]]).
- First, a blockchain performance prediction model is trained using ensemble learning. ([[.raw/papers/bpo-cbs-a-data-driven-blockchain-performance-optimization-framework-for-cloud-blockchain-services#Page 1|PDF p. 1]]).
