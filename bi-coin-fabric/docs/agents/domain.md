# Domain Docs

This repository uses a single context: `CONTEXT.md` and `docs/adr/` at the root.

## Before exploring

- Read `CONTEXT.md` for the terms relevant to the task.
- Read ADRs under `docs/adr/` that touch the area being changed.
- If a document is absent, proceed without proposing one solely for setup.

## Use the glossary's vocabulary

Use terms defined in `CONTEXT.md` in issues, proposals, hypotheses, and tests. If a needed term is missing, note the gap for domain modeling.

## Flag ADR conflicts

Surface a conflict with an existing ADR explicitly instead of silently overriding it.
