# Frontend experience boundaries

The frontend remains one deployable React bundle with two role-selected experiences: an institutional shell for Bank Indonesia, Participants, and Auditors, and a retail shell for Retail Customers and Merchants. Native hash routes make screens bookmarkable and preserve browser back/forward behavior without adding a routing dependency. Institutional navigation is organized by operational goal; retail payments share one Pay workspace. The guided thesis demonstration uses real role handoffs.

This boundary keeps thesis-critical issuance, conversion, wallet funding, participant lifecycle, transfer, and supervision visible as primary work. KYC remains a demonstrable prototype capability and does not change backend or chaincode authorization.
