# Fabric benchmark measurement contract

The primary performance study measures direct Fabric traffic with isolated transaction types; API and PostgreSQL/KYC behavior is evaluated in a separate end-to-end demonstration. Offered TPS is submitted transactions divided by the measured window, Achieved TPS is successful completions divided by that same window, and a load is sustainable only when all five repetitions achieve at least 99% success with successful-transaction p95 latency at or below 2.5 seconds. Caliper worker calibration tests 1, 2, 4, and 8 workers and fixes the smallest worker count that sustains the highest passing load. Low-contention and deliberate shared-key contention are reported separately, while cross-border interoperability remains outside the benchmark.
